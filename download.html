폰 홈 화면에 게임 추가하기

  1. 갤럭시 · Android: Chrome에서 위의 플레이 버튼을 열고 ⋮ → 설치 및 바로가기 만들기 → 설치를 선택하세요. 버전에 따라 홈 화면에 추가로 표시될 수 있습니다.
  2. iPhone: Safari에서 플레이 화면을 열고 공유 → 홈 화면에 추가를 선택하세요. 웹 앱으로 열기가 보이면 켜 주세요.
  3. 휴대폰의 자동 회전을 켜면 가로·세로에 맞춰 화면이 바뀝니다. 커스터마이징에서는 미리보기 아래의 크게 버튼으로 선수를 자세히 볼 수 있어요.

PC와 폰의 기록은 자동으로 동기화되지 않습니다. 설정 → 저장에서 게임 파일을 내보내고 다른 기기에서 가져오면 이어 할 수 있어요.

  1. HTML 파일: 다운로드가 끝나면 파일을 더블클릭해 Chrome 또는 Edge로 열어 주세요.
